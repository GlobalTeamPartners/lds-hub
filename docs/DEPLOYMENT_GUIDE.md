# 🚀 РУКОВОДСТВО ПО РАЗМЕЩЕНИЮ ХАБА НА ДОМЕНЕ (DEPLOYMENT GUIDE)
### Как за 2 минуты подключить этот хаб к вашему домену и использовать как полноценную онлайн-CRM

Этот хаб создан как автономное, сверхбыстрое веб-приложение (SPA), не требующее сложных серверов или баз данных. Все данные сохраняются мгновенно в браузере каждого участника (`localStorage`) и могут синхронизироваться через экспорт/импорт файла JSON или через подключение облачной БД (Supabase / Firebase).

---

## ВАРИАНТ 1: ПОДКЛЮЧЕНИЕ СВОЕГО ДОМЕНА ЧЕРЕЗ GITHUB PAGES (БЕСПЛАТНО И АВТОМАТИЧЕСКИ)

Репозиторий уже находится на GitHub: `https://github.com/unityspirit/globalteampartners`.

1. **Включите GitHub Pages:**
   * Откройте репозиторий: `Settings` $\rightarrow$ `Pages` (в левом меню).
   * В блоке **Build and deployment**:
     * Source: `Deploy from a branch`
     * Branch: `main` / `/ (root)`
     * Нажмите **Save**.
   * Через 60 секунд сайт станет доступен по адресу: `https://unityspirit.github.io/globalteampartners/`

2. **Привяжите ваш собственный домен (например, `hub.globalteampartners.com` или `ldshub.ru`):**
   * В том же разделе `Settings` $\rightarrow$ `Pages` найдите поле **Custom domain**.
   * Введите имя вашего домена (например, `hub.yourdomain.com`).
   * В панели управления вашего регистратора доменов (Reg.ru, Namecheap, Cloudflare) добавьте DNS-запись:
     * Для поддомена: запись **CNAME** с именем `hub` и значением `unityspirit.github.io.`
     * Для главного домена: **A-записи** на IP-адреса GitHub:
       * `185.199.108.153`
       * `185.199.109.153`
       * `185.199.110.153`
       * `185.199.111.153`
   * Поставьте галочку **Enforce HTTPS** (бесплатный SSL-сертификат выдается автоматически).

## ВАРИАНТ 2: ДЕПЛОЙ НА VERCEL / NETLIFY / CLOUDFLARE PAGES В 1 КЛИК

1. Зайдите на [Vercel.com](https://vercel.com) или [Netlify.com](https://netlify.com).
2. Нажмите **Add New Project** $\rightarrow$ **Import Git Repository**.
3. Выберите репозиторий `unityspirit/globalteampartners`.
4. Нажмите **Deploy** (все настройки по умолчанию, так как проект не требует сборки).
5. В настройках проекта Vercel/Netlify добавьте ваш домен в разделе **Domains**.

---

## ВАРИАНТ 3: РАЗМЕЩЕНИЕ НА СВОЕМ VPS / NGINX / HOSTING

Просто скопируйте файл `index.html` и папку `docs/` в корневую директорию вашего веб-сервера (например, `/var/www/html/` или через FTP на обычном хостинге). Никаких NodeJS или Python бэкендов настраивать не нужно.

## 🛠️ ФУНКЦИОНАЛ ВОРКСПЕЙС-CRM ДЛЯ ВАС И ДЛЯ АРТИСТА

1. **Переключатель ролей в шапке:**
   * **Продюсер (GTP):** Создание задач, смена статусов, загрузка мастеров, публикация отчетов.
   * **Артист (Р. П. ГОСТ / Mad Nekit):** Просмотр прогресса, отметка своих пунктов в чек-листах, добавление комментариев.
   * **Командный (Все):** Единый общий обзор.

2. **Канбан-доска CRM:**
   * 4 колонки: *💡 Бэклог*, *⚡ В работе (GTP)*, *🎙️ Действие артиста*, *✓ Готово*.
   * Фильтры по направлениям: Звук, Видео, SMM/Шортс, 100PRO, Live/Радио, Sync.
   * Перетаскивание задач (Drag & Drop) или редактирование через всплывающее окно.

3. **Воронка 5 ключевых релизов:**
   * Альбом «4 LIFE» (100PRO)
   * Клип «Так закалялась сталь»
   * Live в Tip Top Barbershop
   * Эфиры VTRNK Radio
   * Сольный альбом Mad Nekit
   * *Интерактивные чек-листы:* клик по чекбоксу автоматически пересчитывает процент готовности релиза.

4. **Хранилище ассетов и ссылок (Asset Vault):**
   * Централизованный список ссылок на облачные диски (Яндекс.Диск, Google Drive, Telegram-файлы, YouTube).
   * Категории: Мастера звука, Видео-исходники, Обложки/Canvas, Документы.

5. **Журнал движения и комьюнити-чат:**
   * Возможность в любой момент написать заметку или отчет с авторской меткой и точным временем публикации.

6. **Резервное копирование и синхронизация (Бэкап JSON):**
   * Кнопка **💾 Бэкап JSON**: сохраняет весь актуальный прогресс, задачи и ссылки в файл `gtp-lds-hub-backup.json`.
   * Кнопка **📥 Загрузить**: позволяет перенести данные на любой новый компьютер, телефон или привязать к новому домену.
